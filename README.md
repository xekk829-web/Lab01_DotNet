### Ответы на вопросы
1. Чем Console.Write() отличается от Console.WriteLine()?
> `Console.Write()` выводит текст в консоль без перехода на новую строку, а `Console.WriteLine()` с переходом.
2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?
> Возникнет ошибка компиляции.
3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?
> Потому что в C# используется строгая типизация данных и деление целых чисел результат тоже будет целым. Дробный результат можно получить если хотя бы одно из чисел будет дробным (`10.0 / 3`).
4. Что означает var в C#? Чем он отличается от динамической типизации в Python?
> С помощью указания `var` компилятор самостоятельно определяет тип данных в переменной и закрепляет его за переменной, то есть нельзя написать:
>```csharp
>var a = 10;
>a = "Hello";   // Ошибка компиляции
>```
>Это вызовет ошибку, в отличии от Python:
>```Python
>a = 10
>a = "Hello"    # Ошибки не будет
>```
